# Data Studio Transition Strategy

**Date:** 2026-06-20
**Subject:** Looker Studio Rebranding to Data Studio and Webhook Integration

## 1. Overview
Google has reintroduced Data Studio (formerly Looker Studio) as the front door for AI-driven data exploration and reporting. For Jenga365, this rebranding means our ESG reporting and Corporate Partner dashboards will now be served under the "Data Studio" name.

## 2. Impact on Jenga365 Architecture
- **In-App Reporting UI:** We still rely on embedded dashboards for ESG reporting. Looker Studio embeds are now Data Studio embeds.
- **Reporting Infrastructure:** Data Studio will continue to natively query our Neon PostgreSQL database using our pre-computed `pgView`s (e.g., `v_project_location_plantings`, `v_partner_impact`).
- **Database Schema:** We have updated the `corporate_partners` table to use `data_studio_report_id` and `data_studio_share_url` to accurately reflect the new terminology.

## 3. Data Studio Webhooks
With the rollout of Data Studio Pro, organizations get deeper integration capabilities, including webhooks. For Jenga365, this opens new possibilities:
- **Event-Driven Notifications:** We can configure Data Studio webhooks to notify our backend when a partner views a report, allowing us to track stakeholder engagement accurately.
- **Automated Exporting:** Webhooks could trigger PDF or scheduled report exports generated by Data Studio, streaming them directly into Jenga365 or a partner's inbox.
- **Data Sync Triggers:** Webhooks might alert us when Data Studio successfully refreshes data from slow sources, letting our application know when the latest ESG metrics are "live."

*Note: For now, the integration remains focused on embedding dashboards until we finalize the scope of webhook implementation.*

## 4. Configuration Steps for Data Studio
To set up a partner dashboard in Data Studio:
1. **Create the Data Source:** Open Data Studio and connect to the Neon PostgreSQL database.
2. **Select the View:** Point the connector to the appropriate partner-isolated view (e.g., `v_partner_XYZ_impact`) or a filtered aggregate view.
3. **Build the Dashboard:** Add the required charts (trees planted, survival rates, mentorship hours, etc.) using the Data Studio Pro interface or by cloning a template.
4. **Configure Embed and Share:**
   - Enable "Embedding" in the report settings.
   - Generate a login-free "Shareable Link".
5. **Update Jenga365:** Use the admin tools to save the Report ID and Share URL into the Corporate Partner's record. This will instantly render the Data Studio report in their Jenga365 dashboard.
